# 0015 — The shrine can play a seat; built first as the test harness
Date: 2026-09-20 · Brainstorm ruling (Q3)

A scripted seat emits tap events over the same MATCH protocol as a human shrine; the arbiter and
the rules crate cannot tell the difference. It is built **first as the test harness** — every rules
and protocol test drives games through it — and then exposed as a practice opponent in Duel and as
the arena's own castle in **Siege** (Q19). The Bard may narrate it once a board with the DRAM runs
it. Puzzle mode (fixed boards, find the winning taps) stays open as cheap teaching content.
