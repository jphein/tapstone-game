# 0023 — Set 1 is fourteen designs, generated from TOML
Date: 2026-09-20 · Phase 1 implementation ruling

The twelve-card test set gained **Mend** (Neutral, 1, heal 2) and **Riptide** (Tide, 3, destroy a
unit with toughness ≤ 2). Reason: no set 1 card carried the Heal or Destroy effect, so two of the
engine's five spell arms were unreachable by any test or transcript; a rules arm without a card is
dead code with a hash-chain surface.

`SET1` is a `&[CardDesign]` slice generated by `tools/compile_cards.py` from
`game/cards/set1/st1-000..013.toml` into a marked region of `cards.rs`; the TOML is the source of
truth and `--check` gates drift. Reason: designs are data (0010 puts art in a flash partition for
the same reason), the generator enforces the closed vocabularies once, and a later set gets its own
markers without touching set 1.
