# 0007 — Mana: charge the shrine
Date: 2026-09-20 · Brainstorm ruling (Q1)

Once per round a player may tap any card from hand as **charge**: it becomes one permanent mana for
the rest of the game (it is set aside face-down, see 0008). Casting costs mana; unspent mana carries
nothing over — each round you have as many mana as cards you have charged. Every card is therefore
a resource, there are no dead draws and no resource cards to print, and the choice of what to give
up is the game's first real decision each round.

The shrine reads the same UID for cast and charge, so a tap prompts **cast or charge** (touch, or
by card: tap again within 3 s = charge, otherwise cast; see 0009). Rejected: fixed ramp (flat),
resource cards (screw on 25-card decks, more printing), real-time mana (breaks the tap rhythm).
